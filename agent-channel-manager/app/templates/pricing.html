Agent pricing rules

Rules apply in priority order. Floors protect margin; markups charge agents more; discounts cut prices (with a feed-risk warning); code exclusions block discount codes at agent checkout.

Google Shopping price-match: discount rules lower the price an agent pays below your advertised price, which can trigger Google feed disapproval. You'll be asked to acknowledge this risk when creating a discount rule. Prefer agent-only promotions (bundles, free shipping) to win on value without touching the advertised price.
