## Long description
AI agents are already shopping your store. ChatGPT, Copilot, and Google AI Mode
recommend products and compare prices on your behalf — whether you've planned
for it or not.

Agent Channel Manager gives you a control panel for this new sales channel:

- **Product visibility controls** — run a blocklist (hide low-margin or
  MAP-sensitive SKUs from agents) or an allowlist (agents see only what you
  approve), per product or per collection.
- **Agent-specific pricing** — set price floors so agents never see a
  margin-killing price, add percentage markups, or exclude discount codes
  from agent checkouts.
- **Agent-only promotions** — bundles and free-shipping thresholds that win
  machine-made comparisons on *value* instead of raw price. Each promotion
  syncs an unlisted discount code — never shown on your storefront.
- **Margin guard simulator** — preview exactly what an AI agent sees:
  visible products, agent prices, margin impact, and Google Shopping
  feed-risk flags, before it costs you money.

Built-in Google Shopping guardrail: discount rules that would undercut your
advertised price require explicit acknowledgement, so you never accidentally
risk feed disapproval.

If your only answer to an AI agent is a price, you're in an auction. This app
lets you compete on your terms.

## FAQ (draft)
**Do I need this if Shopify already shows agent traffic?** Shopify's dashboard
shows you the traffic. This app lets you *control* it — what agents see and
at what price.
**Will this change my storefront prices?** No. Agent pricing rules only affect
what AI agents see. Your storefront is untouched.
**What happens when I uninstall?** Your channel configuration is deleted per
Shopify's privacy requirements.
